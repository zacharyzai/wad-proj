Core Features ✨

Feature Description
🔐 Authentication Secure registration and login with bcrypt password hashing and session management. Role-based access (student / organizer / admin) enforced throughout the application.
📋 Event Discovery Browse paginated events (5 per page). Filter by category, sort by upcoming / past / popular, and search by event title or location.
✅ RSVP System Reserve your spot at any event. The system enforces capacity limits and prevents duplicate RSVPs. Cancel attendance at any time.
⭐ Reviews & Ratings Rate events 1–5 stars and leave a titled review with a comment. Only verified attendees can post reviews. Reviews can be edited or deleted by their author or an admin.
🔔 Notifications In-app notifications keep everyone informed — organizers are alerted on new RSVPs and reviews; attendees are notified when their event is updated or cancelled.
📊 Admin Analytics Visual dashboard (Chart.js) showing events per month, user role breakdown, category distribution, total RSVPs, and the top 5 most attended events.
🎯 Recommendations Personalised event suggestions based on each student's past RSVP and attendance history.
👤 User Profiles Each user has a profile with name, email, student ID, faculty, and a short bio (up to 200 characters). Accounts can be fully deleted, cascading to all associated reviews, RSVPs, and events.
